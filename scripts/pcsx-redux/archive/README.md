# Archived PCSX-Redux probes

One-off capture probes that no doc, script or source file references. Each
answered one question at the time it was written; the answer lives in the
doc that records the finding, and the probe stays here as its provenance and
as a starting point for a similar capture. They run the same way as the live
probes ([`docs/tooling/pcsx-redux-automation.md`](../../../docs/tooling/pcsx-redux-automation.md));
a probe that becomes the instrument behind a documented claim moves back up
to `scripts/pcsx-redux/` and gets cited there.
