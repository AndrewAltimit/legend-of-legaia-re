Read how it works

docs zone

The project runs on two tracks that feed each other. Preservation gets every asset off the disc and writes down each file format, with every claim traced back to the game's own code. Reimplementation is a from-scratch rewrite of the engine in Rust, built from those documents rather than from Sony's executable - so it can run the game faithfully and also go beyond it (dynamic lighting, see-through walls, VR) with the retail look one toggle away. The docs below are the shared ground truth for both.
