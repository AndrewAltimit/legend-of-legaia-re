Reference

Lookup tables, not reading. Where a fact about the game is filed: which function does what, what sits at an address, what a track is called, and which questions are still open. Every row carries the function, capture or cheat code behind it, so if a claim elsewhere on the site looks surprising, the evidence is here.

Names and labels

Curated game-data tables
Arts, magic, items, equipment, enemies, shops, casino and fishing tables from public walkthroughs - the labels disc records are checked against.
Cheat databases

Scene names
