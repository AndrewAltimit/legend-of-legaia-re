Reference

Lookup tables, not reading. Where a fact about the game is filed: which function does what, what sits at an address, what a track is called, and which questions are still open. Every row carries the function, capture or cheat code behind it, so if a claim elsewhere on the site looks surprising, the evidence is here.

Which table do you want?

Reference pages

Key functions
The traced functions that matter, grouped by subsystem: boot, asset loader, the VMs, cutscenes, renderer, battle, menus, audio, world map. Explains the FUN_80xxxxxx naming and the overlay-window trap.
PSX RAM map
The 2 MB main RAM as a picture: where the executable loads, where overlays go, where the party's records, inventory and story flags live.
Cheat databases
GameShark codes as hardware-verified RAM addresses: encoding, parser, what each region pins, and the engine's cheat applier.
Curated game-data tables
Arts, magic, items, equipment, enemies, shops, casino and fishing tables from public walkthroughs - the labels disc records are checked against.
Music tracks
Every BGM cue across its four naming spaces - sound-test id, in-game context, OST title, proposed relocalization - and the disc join behind it.
Builds + region differences
14 known builds across NA / JP / EU / demo / preview / debug. SCUS_942.54 is the NA build the project targets.
Open RE threads
The live list of unsolved questions, each with the next step that would close it. Start here to contribute.
Settled RE threads
Answered questions, each graded by what its evidence rests on: instructions, a runtime capture, decompiled C, or inference.
Do not re-walk
Readings of the bytes that looked right and were disproved, with the reasoning kept so nobody repeats the walk.
