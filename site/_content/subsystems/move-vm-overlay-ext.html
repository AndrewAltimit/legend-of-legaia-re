Move VM: the 0x2F overlay extension

The move VM’s opcode 0x2F hands the instruction to a second dispatcher that lives in the field overlay rather than the main executable. Its 61 sub-opcodes are the vocabulary field effects need and battle effects do not: player-relative tests, story-flag branches, shared scratch slots, self-modifying bytecode, curve motion and colour ramps. Every field scene’s ambient effect tree is written in it.

Dispatch

  • No out-of-bounds jump exists. The sub-opcode is loaded sign-extended and compared unsigned, so a negative value reads as huge and is rejected with a width of 1. That matters because the bytecode is writable by the program itself.
  • One copy, one caller. The six capture-derived dumps of this address disassemble byte-identically to the static one: it is one function seen under different scenario labels, not a per-overlay family. A five-form reference scan over the executable, every overlay image and every raw archive entry finds one reference to it.
  • Read each width from the disassembly. The decompiled C hides it; each arm loads its own return value before the shared epilogue.

The random draws in 0x05 and 0x30 are the BIOS rand. 0x05’s divide is signed, and a zero divisor traps on retail.

The shared scratch table

Sixteen slots of eight bytes at 0x801F3498, shared across actors. That is how parts of one effect tree hand each other positions, tween sources, render banks and scales: one part saves, a sibling loads. The cycle counter wraps mod 16 for the same reason - it indexes this table.

Why programs rewrite themselves

Seven sub-ops write a value computed at run time - a world position, a random value, a copy, an increment, the angle to the player, a party member’s position - into the operands of a later instruction of the same program. A program can therefore fly a part toward where the player is by writing that position into the lerp that follows it. A static disassembly of such a program shows the placeholder, not the value; the bounds check above is what keeps a rewritten sub-opcode from jumping out of the table.
