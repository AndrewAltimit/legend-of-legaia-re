Script VM internals

The reference half of the field / event script VM: the context record, every opcode with its byte width, the sub-op tables of the sub-dispatchers, all sixteen 0x4C nibbles, and the traps that catch anyone reading the dump. Widths are in bytes and include the opcode; an 0x80-flagged (targeted) form adds one target byte after the opcode.

At a glance

Dispatcher
FUN_801DE840(buffer, pc, ctx) in PROT 0897, returns the new PC. Dump ghidra/scripts/funcs/overlay_0897_801de840.txt.
Three exits
Advance (add the op's width), halt at PC (return the PC unchanged, so the op re-runs next frame - how every wait works), halt-acquire (freeze another actor by setting its halt bit and parking its resume pointer).
PC
A signed 16-bit halfword at ctx+0x9E: every relative jump is (base + delta) mod 0x10000, so 0xFFFE is "back 2".
In the port
engine-vm::field (step.rs per opcode), engine-vm::field_helpers (the pure leaf helpers), legaia_asset::field_disasm (widths for every opcode and every 0x4C nibble).

The context record

Each running script has a context, which for a placement is the actor record itself. Selected fields:

OffsetTypeMeaning
+0x10u32Flag word: 0x100 engaged (the script runs), 0x400 halted (mid-walk or halt-acquired), bits 0/1 collision- and touch-exempt (a door runs 31 00 as its swing starts), 0x20000 / 0x40000000 the contact class (button-gated props), 0x1000 animating
+0x14/16/18i16World X / Y / Z; a tile byte b becomes (b & 0x7F) × 0x80 + 0x40, plus 0x40 if the high bit is set
+0x26u16Heading (12-bit angle)
+0x50u16Script id / bind index (0xFB = system)
+0x54u16Wait accumulator: cleared by a motion park, ticked by WAIT_FRAMES
+0x5Ci16Move-table index (EXEC_MOVE)
+0x62u16Local flag bank, 16 bits; also the clip-control word whose bit 8 the clip tick latches at a clip's end
+0x72u16Render scale, 0x1000 = 1.0; 0 = invisible (trigger gizmos run 4C 40 00 00)
+0x74 / +0x78u32 / u16Draw word (tint colour + mode bits) and tint blend, written by 4C 81
+0x90u32Script buffer base
+0x94u32Resume pointer of a parked motion op (or a halt-acquire payload)
+0x9Cu8Dialog state: 1 waiting for the box, 2 owns the box
+0x9Ei16Program counter

The player context pointer is _DAT_8007C364; many opcodes branch on "is the context the player". The full field table is in script-vm.md.

0x3E battles and minigames

0x4C MENU_CTRL: sixteen dispatchers in one opcode

Despite the name, 0x4C is not a menu op. The high nibble of op0 indexes a 16-entry jump table, most arms index a second table on the low nibble, and every sub-op has its own width - which is why a linear disassembler has to know all of them.

4C D3 expiry:u16 below:u16 duration:u32 threshold:u32 (14 bytes) schedules a countdown in the save block. The per-tick consumer FUN_801D2EBC sets the expiry flag at zero and the below flag while under the threshold. Retail use: chitei2's collapsing-dungeon escape (flag 0x4C7, 2400, threshold 910). A mid-timer save keeps it.

4C D4 / D5 x:u16 y:u16 (6 bytes) read a 16×1 VRAM strip, set (D4, non-zero pixels) or clear (D5) the transparency bit, and write it back. It decides whether a CLUT entry a colour cycler later takes to black reads as opaque black or as transparent - teien marks its hedge CLUTs before installing the dusk cycler.

Reading the dump

  • Label-calls. Ghidra renders the shared epilogue as a call. In the assembly each arm exits with addiu s8, s8, N in the delay slot of j 0x801df09c, and that N is the op's PC advance. Labels promoted to fake functions: 0x801df098 (+2), 0x801df09c (+0), 0x801df8dc (+6), 0x801e00b8 (+3), 0x801e212c (+7), 0x801e3614 (BBOX outside), 0x801e3620 (+4). Grep the address in the dump before treating it as a callee.
  • Delay slots hide advances. The motion ops advance past themselves for every target (li s7, 4 in a delay slot); only a player target also parks the caller. The decompiled C hides this.
  • 16-bit jumps. [21] [26 FE FF] is the park-here idiom. A port that adds the delta in a wider integer turns every backward jump into a forward overrun.
  • Pure helpers. packet_length (FUN_8003CA38), party_flag_test (FUN_8003CE64), small_table_search (FUN_80042EE0), the little-endian loaders (FUN_8003CE9C / CEB8 / CED8) and the inlined tile_center are ported as functions in engine-vm::field_helpers.

Flag census: when a row lies

The census walks bytecode linearly, and four things mislead it. A marked row means "check the record disassembly", never "discard".

  • Text aliases. Dialogue bytes land on the flag ops: S..W read as Set, a..g as Clear, q..w as Test. Rows carry clean and text_alias marks; a non-printable operand cannot be minted by prose.
  • Width blindness. A wrong sub-op width desyncs the walk and hides a real site behind a phantom; every 0x4C nibble decodes with the executing VM's widths.
  • Variant carriers. The census walks the bundle MAN and the streaming variant MANs (--variant <entry>); --p2-gates prints the partition-2 spawn conditions.
  • Developer flag menus. Several shipped records carry a debug picker whose options write the scene's flags (Set all flags / Clear / Exit in Jeremi's inn). Their rows are clean and real, and mean "an option nobody picks in retail play"; they carry debug_menu.

FMV triggers and the disassembler

Only two code paths start a movie: the field op 4C E2 (its u16 operand is the FMV id) and the title attract loop (movie 0). Eight scenes carry a 4C E2: town01, garmel, deroa, chitei2, dohaty, town0d, uru, jouine; the operands decode statically from each MAN (cutscenes).

asset field-disasm file <PATH>
asset field-disasm scan-prot --prot <PROT.DAT> --cdname <CDNAME.TXT> --bytewise

The walker mirrors the executing VM's widths without side effects, so any byte buffer is safe input. A 4C E2 hit inside a move-VM prescript record is a false positive.

Readings this page replaced

  • The prescript table was read as field-VM bytecode; it is move-VM stager records.
  • Op 0x39 was labelled PLAY_SFX; it is the item give. Op 0x36 was labelled SCENE_FADE; every arm is sound. Op 0x3E with op0 < 100 was read as an NPC-interaction opener; it is the scripted-battle install.
  • 4C 30 was read as an input lock; it raises the ambient-particle gate. Nibble 9 was read as a fade family; it is the floor-height ladder.
  • The story-flag base was mislabelled DAT_80086D70 by double-counting the save-block displacement.
