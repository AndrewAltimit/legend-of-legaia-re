Site redesign — five proposals

Each file below is a full mockup: the homepage, an interactive page (Enemy table), and a docs page (Legaia TMD spec) — same content in all five, so the comparison isolates the design. Open them in tabs and flip between them.

What every proposal fixes (independent of the visual direction)

  • Two-zone IA Explore (interactive) and Docs (reference) split at the top level; the 70-link flat sidebar is gone. Docs keep a sidebar — scoped to docs only.
  • Tool-first pages On interactive pages the tool is the first thing on screen; explanatory prose collapses below it.
  • Show, don't tell One-line hero + CTAs; cards get thumbnails and one-line bodies; the legal note becomes a badge.
  • Disc-status chip Pick the disc once in the header, every page reflects it — no per-page "Open a disc image" section.
  • Progress as stat strip Four tiles, one accent, one methodology link — no paragraph.
  • Docs keep their depth Byte tables and provenance stay; they gain a metadata strip (confidence · traced functions · crate) and reading-width typography.

The five directions

A
Refined terminal — “keep the soul, fix the ergonomics”
Same dark + cyan identity, but sans-serif UI, mono only for code/data, imagery on cards.
Safest. Least churn, keeps current brand equity — but least likely to change how the site feels.

B
Ra-Seru — “a game site first, a lab notebook second”
Cinematic dark hero, ember/indigo palette from the game, display serif, per-zone accent hues.
Most inviting to players. Risk: needs discipline to not tip into fan-site kitsch.

C
Archive light — “the museum catalog”
Warm paper, serif display, numbered sections, exhibit-framed thumbnails. Preservation-institute identity.
Most distinctive + most readable prose. Risk: light theme is unusual for this audience; 3D viewers sit on dark canvases.
open →
D
Console dashboard — “a launcher, not a wiki” · ★ preferred direction
App shell: icon rail + tile grid with READY / NEEDS DISC badges; docs open in a reader surface. Tiles now carry real screenshots captured from the live pages (engine scenes, minigames, models, texture catalog).
Best for the tools. Treats the site as software. Risk: docs can feel secondary; densest to build.
open →
E
Split portal — “two sites under one roof”
Split hero routes you; Explore is fully playful, Docs keeps the terminal identity on purpose.
Maximum separation — the complaint solved literally. Risk: two design systems to maintain; transitions must feel deliberate.
