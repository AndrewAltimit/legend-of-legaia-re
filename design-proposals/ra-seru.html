Legaia TMD (3D mesh)

CONFIRMED · traced from FUN_80026B4C · FUN_800268DC · FUN_8002735C · implemented in crates/tmd · last verified against SCUS-94254

TMD is the PlayStation SDK's standard 3D model format. Every 3D mesh in Legend of Legaia is a TMD — but it is a custom Legaia variant, not the stock Sony format: standard PSX TMD tools reject these files or produce garbage. This page documents the variant byte-for-byte.

Not stock PSX TMD

The tell is the very first word: Legaia's magic is 0x80000002 instead of the standard 0x00000041. Beyond the magic, the differences run deeper:

  • Custom primitive grouping — primitives are batched behind an 8-byte group header instead of the stock per-primitive packet stream.
  • Offset pointers — the object table's pointer fields are byte-relative offsets the runtime patches to absolute RAM addresses on load.
  • A fixed scale word — the per-object scale field is always 0x00808080, a Legaia-custom value where stock TMD stores a signed log2 scale.

Header (12 bytes)

offsizefieldnotes
0x00u32id always 0x80000002 · bit 31 = FLIST_BIT (pointers relative to header end) · low byte 0x02 = "Legaia TMD v2"
0x04u32flags 0 on disc; runtime sets 1 after pointer fixup
0x08u32nobj number of objects

Object table (28 bytes per object × nobj)

Each object record points at vertex, normal, and primitive arrays with byte-relative offsets, plus the fixed scale word above. The runtime rebases all three pointers on load, then flips flags to 1.
