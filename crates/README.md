# Crates

The workspace crate map. Each crate has a one-page `README.md` describing its scope, format coverage, and how it composes into the pipeline. Crate naming: package `legaia-foo`, lib `legaia_foo` for the game-specific crates; the generic PS1 crates (disc, XA, bytes, TIM, VAB, SEQ, LZS, MDEC, the save-state readers, RAM image, retail-exec) take `psx-foo` / `psx_foo` instead ([`reusing-for-other-ps1-games.md`](../docs/tooling/reusing-for-other-ps1-games.md)). Directories under `crates/` carry no prefix.

## Workspace rules

Every dependency, internal or external, is declared once in the root `[workspace.dependencies]` and taken as `psx-tim.workspace = true` - never a per-crate `path =` or version pin. A crate's command-line binary sits behind its default-on `cli` feature (`required-features = ["cli"]`, `clap` / `libc` optional); the workspace table lists those crates with `default-features = false`, which keeps CLI dependencies out of library builds and the wasm bundle. No crate re-exports another crate's modules: a use site names the crate that owns the code, and each `Cargo.toml` lists exactly the workspace crates its sources name.

The edges among the engine's kernel crates are a committed table (`scripts/ci/crate-layering.toml`, gate `check-crate-layering.py`); a new edge is a row there with its reason - see [`engine.md`](../docs/subsystems/engine.md#the-layering-gate).

The play page holds one for in-world minigame art. Also `LegaiaModes`, the disc-free game-modes page's mode seat. An rlib below `web-play`. |
| [`crates/web-patcher`](web-patcher/README.md) | - | The site's client-side ROM patcher (randomizer, texture replacer, language-pack workbench; nothing is uploaded) as wasm exports over `patcher` and its layer crates. Names no engine crate. An rlib. |
| [`crates/web-expansion`](web-expansion/README.md) | - | The site's expansion workbench as wasm exports: disc pickers and coordinate resolver, pack JSON in / validation / `.lxpack` out, the XP, dialogue and map previews over the engine's own kernels. An rlib in the engine layer. |
| [`crates/web-play-bundle`](web-play-bundle/README.md) | - | The wasm module the play, minigames and game-modes pages load (`cdylib` over `web-play` and `web-minigames` alone, output `site/wasm/play/`); which page holds which bundle is `scripts/ci/page-bundles.toml`. |
| [`crates/web-viewer`](web-viewer/README.md) | - | The tool bundle every other page loads (`cdylib` over `web-play`, `web-patcher` and `web-expansion`), and its own product: the asset inspectors (disc browser, viewers, `.glb` export). |
